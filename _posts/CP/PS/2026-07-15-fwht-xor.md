오늘 풀어본 문제는 CF717D, Dexterina's Lab입니다. Codeforces 기준 1900의 난이도를 가지고 있고, 태그는 games, matrices, probabilities네요.

문제는 Nim 게임에서 출발합니다. 한 무더기에 돌이 0개 이상 $$x$$개 이하 있다고 하고, 무더기가 돌 $$i$$개를 가질 확률 $$P(i)$$가 $$i = 0...x$$에 대해 주어집니다. 이렇게 정의된 무더기가 $$n$$개 있을 때, 선공이 이기게 될 확률을 구해달라고 하네요.

가장 먼저 Nim 게임에 대해 잘 알려진 사실을 떠올려 봅시다. 선공이 이길 조건은 모든 돌무더기의 돌 개수를 xor한 값이 0보다 큰 경우이죠. 따라서 우리는 모든 무더기의 돌 수를 xor한 값이 0보다 클 확률만 구하면 됩니다. 이건 대충 xor한 값이 0일 확률을 구한 다음에 1에서 빼면 되겠네요.

그러면 문제는 그 다음입니다. $$n \leq 10^9$$이기 때문에 모든 분포에 따라 계산하는 방법이 불가능합니다. 그러면 어떻게 계산할 수 있을까요?

무더기가 두 개인 경우부터 생각해 봅시다. xor한 값이 특정 값이 될 확률을 구하기 위해서는, xor한 값이 그 값이 되는 쌍을 모두 구한 뒤 확률을 구해 더하면 되겠네요. 따라서 아래와 같이 나타내어줄 수 있습니다.

$$\text{Pr}(\text{XOR} = k) = \sum_{a \oplus b = k}{P(a)P(b)}$$

뭔가 익숙한 형태이죠? 우리에게 익숙한 Convolution의 형태입니다. 더 명확히 보려면, 다음처럼 쓸 수도 있죠.

$$\text{B}[k] = \sum_{i \oplus j = k}{\text{A}[i]\text{A}[j]}$$

이제 이걸 $$n$$번에 대해 일반화할 수 있습니다. 그냥 이 합성을 $$n$$번 하면 돼요! 문제는 계산입니다.

보통 Convolution 문제는 FFT나 NTT 등을 사용하게 됩니다. 그러나 우리는 (조건 항에서?) 덧셈 연산이 아닌, xor 연산을 하고 있죠. 다행히도 and, or, xor 등에 대해서 convolution을 계산하는
FWHT(Fast Walsh-Hadamard Transform)이라는 알고리즘이 존재합니다. 자세한 내용은 [이 글](https://gina65.tistory.com/30)을 참고해 주세요.
(원래 이 주제에 대해 글을 적으려 했지만 아직 공부가 부족해 미뤄졌습니다)

이제 이 알고리즘을 구현하고, $$n$$번의 Convolution을 각 요소당 $$n$$제곱으로 바꾸어 주면 됩니다. 코드는 다음과 같네요.

```python
class Transform:
    def xor(self, a, inv=False):
        n = len(a)
        le = 1
        while le < n:
            for lft in range(0, n, le * 2):
                for i in range(le):
                    x, y = a[lft + i], a[lft + le + i]
                    a[lft + i], a[lft + le + i] = x + y, x - y
            le *= 2
        if inv:
            for i in range(n):
                a[i] /= n
n, mv = map(int, input().split())
prob = list(map(float, input().split()))
siz = 1
while siz <= mv:
    siz *= 2
prob += [0.0] * (siz - len(prob))
trans = Transform()
trans.xor(prob)
for i in range(siz):
    prob[i] = pow(prob[i], n)
trans.xor(prob, inv=True)
lp = prob[0]
wp = max(0.0, min(1.0, 1.0 - lp))
print(f"{wp:.10f}")
```
