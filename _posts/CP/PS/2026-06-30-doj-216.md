# DOJ 206 말랑말랑 계산 직관 트레이닝
DOJ 기여 기준 Platinum V의 난이도를 가지고 있는 문제입니다. 문제는 $A_i = ai + b$로 정의된 수열 $A$에 대해 다음 값을 구하는 것입니다:

$$\sum^{N}_{i_M = 1}{\sum^{i_M}_{i_{M-1} = 1} \cdots \sum^{i_3}_{i_2 = 1} \sum^{i_2}_{i_1 = 1}A_i}$$

고정된 $a, b$에 관해 관찰을 해보다 보니, $S(N, M) = S(N - 1, M) + S(N, M - 1)$의 관계식을 얻을 수 있었고, 여기서 더 건드려보다 보니 $S(N, M) = \sum_{i = 1}^{N}{\binom{N - i + M - 1}{M - 1}A_i} = \sum_{i = 1}^{N}{_n\mathrm{H}_r}$을 얻을 수 있었습니다.

여기서 $A_i = ai + b$임을 이용하면 식을 두 개의 항으로 분리할 수 있습니다. 

$$\sum_{i = 1}^{N}{_n\mathrm{H}_rA_i} = a\sum_{i = 1}^{N}{_{N - i}\mathrm{H}_{M - 1}}i + b\sum_{i = 1}^{N}{_{N - i}\mathrm{H}_{M - 1}}$$

이를 다시 써보면 다음과 같습니다.

$$a\sum_{i = 1}^{N}{_{N - i}\mathrm{H}_{M - 1}}i + b\sum_{i = 1}^{N}{_{N - i}\mathrm{H}_{M - 1}} = a\sum_{i = 1}^{N}{\binom{N - i + M - 1}{M - 1}i} + b\sum_{i = 1}^{N}{\binom{N - i + M - 1}{M - 1}}$$

여기서 $b\sum_{i = 1}^{N}{\binom{N - i + M - 1}{M - 1}}$는 하키스틱 법칙을 이용해 계산할 수 있습니다. $b\sum_{j = 0}^{N - 1}{\binom{j + M - 1}{M - 1}}$ 형태로 식을 변형한 뒤 하키스틱 법칙을 적용하면 $\binom{N + M - 1}{M}$이 됩니다.

그러면 $a\sum_{i = 1}^{N}{\binom{N - i + M - 1}{M - 1}i}$는 어떻게 계산할 수 있을까요? 이번에도 하키스틱 법칙을 적용하려고 하면 $i$가 문제가 됩니다. 저는 이거에 막혀서 대략 10분 정도 인터넷을 뒤져보다가 가중 하키스틱 법칙?을 찾아서 적용했습니다. (사실 그냥 하키스틱을 두 번 쓰는 거에요)

$a\sum_{i = 1}^{N}{\binom{N - i + M - 1}{M - 1}i}$을 하키스틱 법칙이 적용 가능한 상태로 변형하면 $a\sum_{j = 0}^{N - 1}{\binom{j + M - 1}{M - 1}(N - j)}$가 됩니다. ($j = N$ 항은 값이 0이라 제거할 수 있습니다)

이걸 다시 한번 변형하면 $a\sum_{x = 0}^{N - 1}{\sum_{j = 0}^{x}{\binom{j + M - 1}{M - 1}}}$이고 안쪽 $\sum$에 하키스틱 법칙을 적용하면 $\sum_{j = 0}^{x}{\binom{j + M - 1}{M - 1}} = \binom{x + M}{M}$입니다. 이를 대입하고 다시 한번 하키스틱을 적용하면 $a\binom{N + M}{M + 1}$이 되죠.

따라서 우리는 다음의 식을 얻습니다.

$$S(N, M, a, b) = a\binom{N + M}{M + 1} + b\binom{N + M - 1}{M}$$

이제 나머지는 계산뿐입니다. 모듈러가 적용되어 있어 팩토리얼 전처리를 적용했고, 혹시 몰라 모든 쿼리에 대해 $N + M$의 최대값을 구한 후($K$라고 합시다) $K$까지만 전처리를 진행했습니다.

매번 전처리를 진행하면 최악의 경우 $O(KQ)$의 시간이 걸리지만, 이렇게 한번만 전처리하면 $O(K + Q)$로 줄일 수 있습니다. (여기서 $K = \max_{\text{queries}}{N + M}$입니다.)

<summary>전체 코드</summary>
```python
import sys
import math
input = lambda: sys.stdin.readline().rstrip()
mod = 1_000_000_007
Q = int(input())
class Query:
    def __init__(self, N, M, a, b):
        self.N = N
        self.M = M
        self.a = a
        self.b = b
queries = []
nm_max = 0
for _ in range(Q):
    N, M, a, b = map(int, input().split())
    nm_max = max(nm_max, N + M)
    queries.append(Query(N, M, a, b))
fact = [1] * (nm_max + 1)
for i in range(1, nm_max + 1):
    fact[i] = fact[i-1] * i % mod
invfact = [1] * (nm_max + 1)
invfact[nm_max] = pow(fact[nm_max], mod - 2, mod)
for i in range(nm_max, 0, -1):
    invfact[i - 1] = invfact[i] * i % mod
def nCr(n, r):
    if r <  0 or r > n:
        return 0
    return fact[n] * invfact[r] % mod * invfact[n - r] % mod
def solve(q):
    return (q.a * nCr(q.N + q.M, q.M + 1) + q.b * nCr(q.N + q.M - 1, q.M)) % mod
for q in queries:
    print(solve(q))
```
